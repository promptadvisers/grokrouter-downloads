Four things. Then just chat.

The README walks you through one Mac command, then the normal GrokRouter app does the rest.

Open the repository

Read the short Mac quick start and inspect the installer source if you want to see exactly what runs.

Run the Mac command

Paste one command into Terminal. Your Mac builds GrokRouter locally and opens it from your Applications folder.

Open Grok Bot

Leave Grok Bot visible. If asked, select any Bot and click Open computer so GrokRouter can finish safely.

Click Install Router

Choose Codex or OpenRouter, install, then create a new Bot and send /router doctor.

Safe to try. Simple to undo.

GrokRouter checks the exact Grok Bot version, keeps a verified stock backup, and refuses unknown builds.

  • Inspectable sourceYour Mac compiles the public Swift app locally. No unsigned downloaded app is distributed.
  • Your key stays protectedOpenRouter keys go directly into Grok Bot's protected Secrets store.
  • One-click restoreRestore Stock Grok Bot puts the original model path back.
  • No broad Mac permissionsNo Accessibility, Screen Recording, or Full Disk Access request.
