Install GrokRouter

On Mac, drag it into Applications. On Windows, run setup and open it from the Start menu.

Open Grok Bot

Leave Grok Bot visible. If asked, select any Bot and click Open computer so GrokRouter can finish safely.

Choose your model

Select Codex, OpenRouter, or both. Add an OpenRouter key only if you want to use OpenRouter models.

Click Install Router

Create a new Bot when it finishes. Send /router doctor, then chat normally inside Grok Bot.
