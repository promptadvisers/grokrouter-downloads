# Security

Only download GrokRouter from this repository's release page or <https://promptadvisers.github.io/grokrouter-downloads/>.

- macOS releases must be signed and notarized by Prompt Advisers.
- Windows releases must identify Prompt Advisers as the verified publisher.
- Every release includes SHA-256 checksum files.
- Do not bypass an unknown-developer or unknown-publisher warning.

GrokRouter is unofficial and modifies a version-gated inference component inside a Grok Bot computer. It refuses unsupported Grok Bot builds, saves a verified stock backup before activation, and includes a Restore Stock action.

Do not post API keys, account details, or private Grok transcripts in public issues. If a credential may have been exposed, rotate it and restore stock Grok Bot before diagnosing further.
