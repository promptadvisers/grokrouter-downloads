# Security

The canonical GrokRouter source is <https://github.com/promptadvisers/grokrouter>.

The supported Mac installer builds the native app locally from that public source. It does not distribute an unsigned app or ask users to bypass an unknown-developer warning.

GrokRouter is unofficial and modifies a version-gated inference component inside a Grok Bot computer. It refuses unsupported Grok Bot builds, saves a verified stock backup before activation, and includes a Restore Stock action.

Do not post API keys, account details, or private Grok transcripts in public issues. Use the main repository's private security-advisory channel. If a credential may have been exposed, rotate it and restore stock Grok Bot before diagnosing further.
